# 🧩 Basic CRUD Operations with Node.js, Express & MongoDB

This project demonstrates **basic CRUD (Create, Read, Update, Delete)** operations using **Node.js**, **Express**, **MongoDB**, and **Mongoose**.  
It is a beginner-friendly backend project to understand how models interact with a database.

---

## 📌 Features

- MongoDB connection using Mongoose
- User model creation
- CRUD operations via Express routes
- Simple and clean project structure
- Uses async/await for database operations

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
